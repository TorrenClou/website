TorrentDrive downloads torrents on your server and uploads them directly to Google Drive or
S3-compatible storage, then cleans up local disk space automatically.

Everything ships as a single container that generates its own secrets on first boot and is
configured entirely in the browser. If you find yourself editing a config file to do something
ordinary, that is a bug — please [open an issue](https://github.com/TorrentDrive/deploy/issues).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/TorrentDrive/deploy/main/install.sh | bash
```

Or with Docker Compose (zero `.env` required):

```bash
curl -fsSL https://raw.githubusercontent.com/TorrentDrive/deploy/main/docker-compose.yml -o docker-compose.yml
docker compose up -d
```

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/TorrentDrive/deploy/main/install.ps1 | iex
```

Docker is the only requirement. Open the URL it prints and complete the 3-step setup wizard.

## What it does

- Upload one or more `.torrent` files, inspect live UDP/HTTP tracker swarm health, and download
  **only the files you actually want**.
- Hardened BitTorrent engine with MSE/PE RC4 stream encryption, strict **BEP 27** private-torrent
  isolation (disabling DHT, PEX, Local Peer Discovery, and public fallback trackers on private
  torrents), and zero UPnP/NAT-PMP gateway noise on cloud VPSs.
- Upload finished downloads to **Google Drive** or **S3-compatible storage** — AWS S3, Cloudflare R2,
  Backblaze B2, DigitalOcean Spaces, Wasabi, and MinIO.
- Uses **your** storage credentials. Nothing is proxied through a third party.
- Continuously probes storage health and automatically reroutes a failing upload to another healthy
  drive instead of giving up.
- Deletes local copies once they are safely uploaded, or lets you purge them on demand.
- Bundled Prometheus and Grafana dashboards for real-time transfer and queue observability.

## Ports

| Port | Default Bind | Service |
|------|--------------|---------|
| 47100 | `0.0.0.0` | Web interface (proxies API calls same-origin) |
| 47200 | `127.0.0.1` | REST API, `/metrics`, and `/hangfire` |
| 47500 | `127.0.0.1` | Grafana dashboards |
| 47600 | `127.0.0.1` | Prometheus metrics |

Only port **47100** needs to be reachable for normal use. Internal admin ports are bound to
`127.0.0.1` by default so they are never accidentally exposed on public VPS interfaces.
