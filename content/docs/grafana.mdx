## Overview

Grafana, Prometheus, and Loki are **bundled and pre-provisioned inside the TorrentDrive container** —
data sources and dashboards are wired automatically on boot.

| Service | Default Local URL | Credentials |
|---|---|---|
| Grafana | `http://127.0.0.1:47500` | Username `admin` · Password generated in `/data/postgres/secrets.env` |
| Prometheus | `http://127.0.0.1:47600` | — |

### Finding Your Grafana Password

On first boot, `entrypoint.sh` generates a random `GRAFANA_ADMIN_PASSWORD` and saves it to
`/data/postgres/secrets.env`. Retrieve it with:

```bash
docker exec torrentdrive grep GRAFANA_ADMIN_PASSWORD /data/postgres/secrets.env
```

Or set your own password before first boot via `-e GRAFANA_ADMIN_PASSWORD=your-secret`.

### Accessing Grafana on a Remote Server

Because port `47500` is bound to `127.0.0.1` by default for security, reach it over an SSH tunnel:

```bash
ssh -L 47500:127.0.0.1:47500 user@your-server
```

Then open `http://localhost:47500` in your browser.

## Pre-Provisioned Data Sources & Dashboards

TorrentDrive automatically provisions:

- **Prometheus** (`http://localhost:47600`) scraping `/metrics` from the API (`:47200`) and workers
- **Loki** (`http://localhost:3100`) for structured container logs
- **TorrentDrive Overview Dashboard** tracking active downloads, upload throughput, job queue depth,
  and worker processing duration

## Key Prometheus Metrics

| Metric | Description |
|---|---|
| `torrentdrive_downloads_total` | Total torrent downloads processed |
| `torrentdrive_downloads_active` | Currently active torrent downloads |
| `torrentdrive_uploads_total` | Total cloud uploads completed |
| `torrentdrive_job_queue_depth` | Pending jobs across Hangfire queues |
| `torrentdrive_job_duration_seconds` | End-to-end job processing duration histogram |
