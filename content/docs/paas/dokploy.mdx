---
title: Dokploy
description: Deploy TorrentDrive on Dokploy in one click using the native template or Docker Compose.
---

Dokploy fronts services with Traefik, so nothing needs to be published on the host and TLS is
terminated automatically. TorrentDrive ships both a Compose manifest (`paas/dokploy/docker-compose.yml`)
and a native Dokploy template blueprint (`paas/dokploy/template.toml`).

## Option A: Deploy as a Compose Service

1. In Dokploy, click **Create Project** → **Compose**.
2. Set Repository to `https://github.com/TorrentDrive/backend`, branch `main`, and Compose Path to
   `paas/dokploy/docker-compose.yml`.
3. Click **Deploy**. First boot takes 1–2 minutes while PostgreSQL initializes and secrets are
   generated into `/data/postgres/secrets.env`.
4. Go to **Domains** → **Add Domain**, select service `torrentdrive`, set **Container Port** to
   `47100`, and enable **HTTPS**.
5. Open your domain to launch the [First-Run Setup Wizard](/docs/first-run).

## Option B: Import the Native Dokploy Template (`template.toml`)

[`paas/dokploy/template.toml`](https://github.com/TorrentDrive/backend/blob/main/paas/dokploy/template.toml)
pre-configures port `47100` routing and auto-generates `PUBLIC_FRONTEND_URL` and `NEXTAUTH_URL` from
Dokploy's `${domain}` generator so Google Drive OAuth callbacks work out of the box.

## Volumes & Persistence

The compose file declares three named volumes (`torrentdrive-pgdata`, `torrentdrive-redis`, and
`torrentdrive-downloads`). Back up `torrentdrive-pgdata` before upgrades — it holds both PostgreSQL
data and `/data/postgres/secrets.env`. See [Updating](/docs/updating).

## Security: Only Port 47100 is Routed

The Dokploy manifest exposes only port `47100` to Traefik. Internal ports (`47200` API/Hangfire,
`47500` Grafana, `47600` Prometheus) stay private inside the container network.
