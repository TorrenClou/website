title: Coolify
description: Deploy TorrentDrive on Coolify with zero manual configuration using magic domain variables.
---

Coolify automatically generates a public URL, provisions TLS via Traefik/Caddy, and injects the
domain into TorrentDrive's environment so there is nothing to configure by hand.

## Steps

1. In Coolify, click **+ New** → **Docker Compose**.
2. Set Repository URL to `https://github.com/TorrentDrive/deploy`, branch `main`, and Compose File
   Location to `/paas/coolify/docker-compose.yml`.
3. Click **Deploy**. First boot takes 1–2 minutes while PostgreSQL initializes.
4. Coolify routes your domain to container port `47100`. Open it and complete the
   [First-Run Setup Wizard](/docs/first-run).

## How the Coolify Magic Variables Work

```yaml
environment:
  - SERVICE_FQDN_TORRENTDRIVE_47100
  - PUBLIC_FRONTEND_URL=${SERVICE_URL_TORRENTDRIVE:-}
  - NEXTAUTH_URL=${SERVICE_URL_TORRENTDRIVE:-}
```

- `SERVICE_FQDN_TORRENTDRIVE_47100` tells Coolify to generate a domain and route traffic to container
  port **47100**.
- `SERVICE_URL_TORRENTDRIVE` passes the full scheme + hostname (e.g. `https://torrents.example.com`)
  into `PUBLIC_FRONTEND_URL` and `NEXTAUTH_URL` so NextAuth sessions and Google Drive OAuth callbacks
  work immediately without manual environment edits.

To use your own custom domain, enter it in Coolify's **Domains** field for the `torrentdrive` service
and redeploy — `SERVICE_URL_TORRENTDRIVE` updates automatically.
